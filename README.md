# Robotics Kinematics Solver

- ABB IRB 120 3 0.6
- Fanuc m900ia 260L
- Fanuc m900ia 350
- Fanuc m900ib 280
- Fanuc m900ib 280L
- Fanuc m900ib 360
- Fanuc m900ib 400L
- Fanuc m900ib 700
- Fanuc m2000ia 900L
- Fanuc m2000ia 1700L
- Fanuc m2000ic 165F
- Yaskawa Motoman Gp7

## Setup

```bash
git clone https://github.com/khoslamanav25/Robotics-Kinematics-Solver.git
cd Robotics-Kinematics-Solver
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
